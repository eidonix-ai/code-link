Quick start

From nothing to an AI coding assistant working in your project, in about five minutes.

Downloads1 · Key2 · Install3 · Connect4 · CodeTipsTroubleshooting

1 · Get your API key

  1. Open llm.eidonix.com/join (or the join link your team gave you).
  2. Enter your work email address and press the button. (Only addresses your organisation has set up can get a key.)
  3. Open the email from no-reply@eidonix.com and click the link in it, then press Create my key.
  4. Copy the key it shows. It is shown only once — keep it somewhere safe, like a password manager. It is yours alone; don't share it.

2 · Install code-link

Windows

  1. Download code-link for Windows and unzip it somewhere you'll keep it, for example Documents\code-link.
  2. Double-click code-link.exe. If Windows says it protected your PC, choose More info → Run anyway.
  3. code-link lives in the system tray at the bottom-right of the screen (you may need to click the ^ arrow to see its icon).

macOS

  1. Download code-link for macOS, unzip it, and drag code-link into Applications.
  2. The first time, right-click it and choose Open, then Open again.
  3. code-link lives in the menu bar at the top-right of the screen.

3 · Paste your key

The first time code-link starts, its Settings window opens and asks for one thing: your API key. Paste it and press Continue. code-link checks the key, picks the right models and turns on web search and document reading. That's all the setup there is.

Want code-link ready whenever you start your computer? In Settings, under Launch, turn on Open at login.

4 · Start coding

  1. Click the code-link icon. If Claude Code (or Codex) isn't on your computer yet, choose Install Claude Code… — one click, no admin rights needed. When a newer version is out, the menu offers Update.
  2. Choose Launch Claude Code… (or Launch Codex…). A small window opens:
    • Model — the server's recommended model is already picked; choose another to try it.
    • Folder — your project's folder. code-link remembers the last one; press Change… to pick another.
    Press Launch. A terminal window opens with the assistant running in that folder.
  3. Type what you want in plain words, for example:
    • "Explain how this project is organised."
    • "Add a function that reads orders.csv and totals the amounts by customer, with a test."
    • "The build fails with this error: … Find the cause and fix it."
  4. Watch it work. It reads files, edits them and runs commands in your project. Safe steps go ahead on their own; anything risky stops and asks you first. Press Esc to interrupt it at any time.

You can open as many sessions as you like — each launch opens another window, and each can use a different model.

Tips

  • Be specific. Say which files, what "done" looks like, and how to check it ("run the tests afterwards").
  • Ask for a plan first on bigger jobs: "Plan this change before editing anything." In Claude Code, Shift+Tab switches between modes.
  • Documents and pictures: mention a PDF, screenshot or diagram by its file name (or drag it into the terminal) and ask about it.
  • The web: ask it to look something up ("check the latest version of this library") — it can search and read pages.
  • A bigger model for hard problems: in Claude Code type /model and choose Opus (set which model that is under More options in the launch window); Sonnet is the everyday default.
  • Use version control. In a git project, the assistant's changes are easy to review (git diff) and undo.
  • Updates: when a newer Claude Code or Codex is available, code-link shows an Update button in Settings.

Troubleshooting

"That key wasn't accepted"

Check you copied the whole key. If it still fails, open your join link again and ask for a new key.

"Can't reach llm.eidonix.com"

Check your internet connection. Some company networks or VPNs block new sites — ask IT to allow llm.eidonix.com.

The terminal opens and closes straight away

Open Settings: if Claude Code or Codex shows as not installed, press Install (or Update). If it still closes, send a screenshot to support@eidonix.com.

Lost key, or a new computer

Open your join link and ask for a new key; paste it into code-link's Settings. Your old key stops working.
