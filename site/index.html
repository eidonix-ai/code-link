What it does

  • Claude Code and Codex, ready to go. Pick a model and a project folder from the code-link menu and a terminal opens with your coding assistant connected. If Claude Code or Codex isn't installed yet (or is out of date), code-link installs or updates it for you.
  • Approvals that don't nag. Safe actions (reading files, running tests, editing your project) go ahead on their own; risky ones (deleting things outside your project, pushing, sending data out) still ask you first.
  • Documents, images and the web. Point it at PDFs, screenshots or diagrams and ask about them; it can search the web and read pages.
  • Leaves your normal setup alone. Only the sessions code-link opens use the Eidonix models. If you also have your own Claude or ChatGPT subscription, it keeps working as before.

Questions

Where does my code go?

Your files stay on your computer. The parts of your code and conversation the assistant needs are sent to llm.eidonix.com to be answered by models on Eidonix-operated hardware, the same way any coding assistant works.

Windows says it protected my PC.

code-link isn't code-signed yet. Choose More info → Run anyway the first time. If your company blocks programs from your Downloads folder, ask IT to allow it.

macOS says it can't check the app.

Right-click code-link in Applications and choose Open the first time.

I lost my key or think someone else has it.

Open llm.eidonix.com/join again and ask for a new key. The old one stops working right away.
